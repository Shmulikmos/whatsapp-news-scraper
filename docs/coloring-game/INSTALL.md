# צביעה קסומה 🎨 — הוראות התקנה על אנדרואיד

משחק צביעה לילדים בהשראת Simply Draw: דפי צביעה עם מילוי בלחיצה, מכחול נצנצים, מכחול קשת, ציור זוהר (ניאון) על רקע כהה, שמירת יצירות — הכול בעברית וללא פרסומות, ללא אינטרנט אחרי ההתקנה.

## שלב 1 — הפעלת GitHub Pages (פעם אחת, מהמחשב)

1. היכנסו לריפו בגיטהאב: `shmulikmos/whatsapp-news-scraper`
2. **Settings** → **Pages**
3. תחת **Build and deployment** → Source: בחרו **Deploy from a branch**
4. Branch: בחרו את הענף `claude/mobile-drawing-game-x5mgpq` ואת התיקייה **/docs** → **Save**
   (אחרי מיזוג ל-main אפשר לבחור את main במקום)
5. אחרי כדקה האתר יעלה בכתובת:

   `https://shmulikmos.github.io/whatsapp-news-scraper/coloring-game/`

> הערה: ב-GitHub בחשבון חינמי, Pages עובד רק על ריפו **ציבורי**. אם הריפו פרטי — או שתהפכו אותו לציבורי, או שתעתיקו את התיקייה `docs/coloring-game` לריפו ציבורי חדש (אלה 5 קבצים בלבד), או שתעלו אותה בחינם ל-Netlify Drop (גוררים את התיקייה לאתר app.netlify.com/drop).

## שלב 2 — התקנה על הטלפון של הילדה

1. פתחו את הכתובת למעלה ב**כרום** בטלפון שלה
2. לחצו על תפריט ⋮ (שלוש נקודות למעלה)
3. בחרו **"הוספה למסך הבית"** (או "התקנת אפליקציה")
4. אישור — וזהו! 🎉

עכשיו יש על מסך הבית אייקון 🎨 "צביעה קסומה" שנפתח במסך מלא כמו אפליקציה אמיתית, ועובד **גם בלי אינטרנט**.

## רוצים קובץ APK אמיתי? (אופציונלי)

אחרי ששלב 1 עובד, אפשר להיכנס ל-[pwabuilder.com](https://www.pwabuilder.com), להדביק את כתובת המשחק, וללחוץ Package for Android — מקבלים קובץ APK להתקנה ישירה.
