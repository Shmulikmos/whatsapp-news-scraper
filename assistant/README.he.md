# CEO HQ — עוזר אישי למנכ"ל עם סוכני משנה

מערכת ניהול מלאה למנכ"ל שמנהל **2 חברות, עמותה וחיים אישיים**, מבוססת Claude Code
עם מסד נתונים ב-Google Drive.

## איך זה עובד

```
אתה (מנכ"ל)
   │  "קיבלתי ליד חדש..." / "מה מצבי היום?" / "סכם את הישיבה..."
   ▼
ראש הסגל (Claude, מוגדר ב-CLAUDE.md) — מבין, מנתב, מוודא סגירת לולאות
   │
   ├── leads-manager        לידים ומשפך מכירות
   ├── meetings-manager     ישיבות, סיכומים, מעקב החלטות
   ├── opportunities-manager הזדמנויות עסקיות
   ├── ideas-manager        קליטת ותעדוף רעיונות
   ├── marketing-manager    קמפיינים ותוכן שיווקי
   ├── strategy-planner     יעדים, OKR, תוכניות אסטרטגיות
   ├── audit-controller     ביקורת, בקרה, סיכונים וציות
   ├── bizdev-manager       שותפויות, שווקים, צמיחה
   └── executive-briefing   תדריך בוקר ותמונת מצב
   │
   ▼
Google Drive: "CEO HQ – מטה ניהול"
   ├── 📊 Database – 11 טבלאות (Sheets)
   ├── 🏢 Company-A / 🏢 Company-B / 🤝 Nonprofit / 🏠 Personal – מסמכים
   └── 📥 Inbox – עדכונים ממתינים
```

## מסד הנתונים

| טבלה | מזהה | תוכן |
|---|---|---|
| Leads | LEAD- | לידים ומשפך מכירות |
| Meetings | MTG- | ישיבות, אג'נדות, החלטות |
| Opportunities | OPP- | הזדמנויות עסקיות |
| Ideas | IDEA- | רעיונות (Impact/Effort) |
| Campaigns | CAMP- | קמפיינים שיווקיים |
| Strategy | STR- | יעדים ו-OKR |
| Audit | AUD- | ממצאי ביקורת ובקרה |
| BizDev | BD- | יוזמות פיתוח עסקי |
| Tasks | TASK- | משימות |
| Decisions | DEC- | יומן החלטות מנכ"ל |
| Contacts | CON- | אנשי קשר |

בכל טבלה עמודת `Entity` שמשייכת כל רשומה לישות: `Company-A` / `Company-B` / `Nonprofit` / `Personal`.

## קבצים

- `CLAUDE.md` (בשורש) — הנחיות ראש הסגל וניתוב.
- `.claude/agents/*.md` — 9 סוכני המשנה.
- `assistant/AGENT_GUIDE.md` — מוסכמות קריאה/כתיבה לנתונים (משותף לכל הסוכנים).
- `assistant/config/database.json` — מפת ה-fileId של כל טבלה ותיקייה בדרייב.
- `assistant/db/` — CLI לקריאה/כתיבה לטבלאות דרך Service Account.
- `assistant/SETUP.he.md` — **התחל כאן**: 2 צעדי ההקמה שנשארו (חשבון נפרד + Service Account).
